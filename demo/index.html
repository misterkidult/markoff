這個頁面已經載入 markoff。按左下角的「留言」，然後點畫面上任何一個元素。 留言只會存在你自己的瀏覽器裡，不會送到任何地方。

標完之後

按「匯出」下載 JSON。每一則會帶著這些東西：

{
  "id": "5f3c…",
  "note": "這行對比不夠",
  "element": { "selector": ".card > p", "text": "這行文字的對比…",
               "computed": { "fontSize": "16px", "color": "rgb(153,153,153)" } },
  "device": { "breakpointLabel": "桌機", "viewport": { "w": 1440 },
              "screen": { "w": 1920, "ratio": 75 }, "browser": "Chrome" }
}

device 這一段是重點：同一句「這裡太擠」，在手機和桌機是兩個問題。 ratio 是視窗佔螢幕多少——明顯小於 100 代表對方是刻意把視窗縮窄測 RWD， 不是螢幕本來就這麼小。

裝進自己的專案

<script src="markoff.js" data-project="my-site" defer></script>

然後開 你的網址/?comment=1。沒有這段 query 的一般訪客 完全看不到任何東西，所以可以跟正式站一起部署。

留言要存到哪，你自己決定

上面那一行是純本機模式——就是這個 demo 現在的樣子。 留言存在對方的瀏覽器裡，靠「匯出」下載 JSON 帶回來。不用架後端， 但對方關掉分頁前得記得按匯出。

要讓留言自動送到你手上，有兩種接法：

只是單純 POST——加一個屬性就好：

<script src="markoff.js" data-endpoint="/api/comments" defer></script>

留言會 POST 到那個網址。送不出去會自動重試。

要送去 Google Sheets、Notion、Slack 或任何地方 ——掛一個 callback，想怎麼送都行：

markoff.onSubmit = async (payload) => {
  await fetch('你的網址', { method:'POST', body: JSON.stringify(payload) });
};

回傳的 Promise resolve 代表送成功，pin 會變實心。

兩種接法的完整說明、payload 長什麼樣、失敗怎麼重試， 都在 README。
