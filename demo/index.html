markoff

在活的網頁上標記，標完就結束。這一頁本身就是 demo——左下角有按鈕。

這個頁面已經載入 markoff。按左下角的「留言」，然後點畫面上任何一個元素。 留言只會存在你自己的瀏覽器裡，不會送到任何地方。

拿來標標看的東西

下面這些元素刻意做得有點問題——間距、對比、行高。挑一個點下去， 打幾個字，看看留言長什麼樣。

標完之後

按「匯出」下載 JSON。每一則會帶著這些東西：

{
  "id": "5f3c…",
  "note": "這行對比不夠",
  "element": { "selector": ".card > p", "text": "這行文字的對比…",
               "computed": { "fontSize": "16px", "color": "rgb(153,153,153)" } },
  "device": { "breakpointLabel": "桌機", "viewport": { "w": 1440 },
              "screen": { "w": 1920, "ratio": 75 }, "browser": "Chrome" }
}

device 這一段是重點：同一句「這裡太擠」，在手機和桌機是兩個問題。 ratio 是視窗佔螢幕多少——明顯小於 100 代表對方是刻意把視窗縮窄測 RWD， 不是螢幕本來就這麼小。

裝進自己的專案

<script src="markoff.js" data-project="my-site" defer></script>

然後開 你的網址/?comment=1。沒有這段 query 的一般訪客 完全看不到任何東西，所以可以跟正式站一起部署。
